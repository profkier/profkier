# Plibrary - Personal Book Tracker

This is a cloned version of the [Plibrary project](https://github.com/0xabdulkhaliq/plibrary) by [@0xabdulkhaliq](https://github.com/0xabdulkhaliq).

## About This Clone

I'm a professor at Johnson County Community College who loves CS and improving my teaching skills. I cloned this excellent book tracking application to study and potentially use in my educational materials.

## About Plibrary

Plibrary is a lightweight personal library book tracker web application that allows users to:
- Add books to their personal library
- Track read/unread status 
- Store data locally using browser's local storage
- Enjoy a responsive, mobile-first design

## Usage

- To add a book to your library, click on the "Add Book" button to open the modal
- Fill up the form with book details (title, author, pages, read status)
- After clicking save, the book will appear in your library
- Mark books as read or unread, and delete books from tracking

## Built With

- HTML5 with semantic elements for better accessibility
- CSS3 with mobile-first responsive design
- Vanilla JavaScript with ES6 classes
- Local Storage for data persistence

## Installation

1. Clone this repository
2. Open `index.html` in your web browser
3. Start tracking your books!
